# Code_Alpha Hangman Game
A simple Hangman game developed in Python as part of my Code_Alpha internship.

# Description
This project is a command-line based Hangman game. This player has to guess the hidden word's one letter at a time.
The player gets a limited number of attempts. If the player guesses the word correctly before running out of attempts, they win the game.

# Features
- Simple and interactive Hangman game 
- Random word selection
- Limited number of attempts
- Displays the progress of the hidden word
- Shows guessed letters
- Win and lose conditions

# Language Used
Python

# How To Run
1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder in VS Code or another Python editor.
4. Run the Python file.

This project was created to practice Python programming concepts and was developed as a part of my internship offered by Code_Alpha.
